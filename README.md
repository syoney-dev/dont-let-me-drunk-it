# Don't Let Me Drunk It

ファミコン風RPGの禁酒サポートアプリ（プロトタイプ）。

- 毎日「のまなかった / のんでしまった」と、100文字までの ひとこと日記を記録
- 右上に禁酒の連続日数を表示
- カレンダーで記録を一覧（のまなかった日は金貨、のんだ日はモンスター）
- 左上のワイプに主人公（男性 / 女性を設定で切り替え）
- 上部中央では、主人公が お酒モチーフのモンスターと戦い続ける（1fps）
- 禁酒日数（0 / 3 / 7 / 14 / 30 / 100日）に応じて、装備・モンスター・UIの装飾が豪華になる

データはブラウザの localStorage に保存されます。ビルド不要の静的サイトなので、GitHub Pages でそのまま公開できます。
